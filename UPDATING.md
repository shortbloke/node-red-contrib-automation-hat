## Note to self

Releasing new versions requires:
- Update [REadme.md](https://github.com/shortbloke/node-red-contrib-automation-hat/blob/master/README.md)
- Update [package.json](https://github.com/shortbloke/node-red-contrib-automation-hat/blob/master/package.json)
- Create new [release](https://github.com/shortbloke/node-red-contrib-automation-hat/releases)
- Publish to npm.org `npm publish`
- Update [Nod Red Library](https://flows.nodered.org/node/node-red-contrib-automation-hat)
